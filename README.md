# Bank Management System

A web-based Bank Management System developed using Python, Flask, HTML, CSS, and SQL.

📌 About the Project

The Bank Management System is designed to provide a simple interface for managing banking-related operations through a web application.

Features

- User login and dashboard
- Customer account management
- Balance viewing
- Deposit and withdrawal pages
- Admin dashboard
- Account-related operations

🛠️ Technologies Used

- Frontend: HTML, CSS
- Backend: Python, Flask
- Database: SQL

📂 Project Structure

Bank-Management-System/
├── app.py
├── requirements.txt
├── style.css
├── templates/
└── static/

🚀 How to Run

1. Install Python on your computer.

2. Clone or download this repository.

3. Install the required dependencies:
   
   pip install -r requirements.txt

4. Run the Flask application:
   
   python app.py

5. Open the local address shown in your terminal in your browser.
